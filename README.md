# Smart Homes and Connected Appliances — IoT Blog

A responsive academic blog website for the topic:
"Smart Homes and Connected Appliances: A Day in an IoT Home"

## Files
- index.html — complete webpage
- style.css — responsive styling
- assets/ — original SVG illustrations used in the blog

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a new GitHub repository, e.g. `smart-homes-iot-blog`.
2. Upload `index.html`, `style.css`, and the complete `assets` folder.
3. Open Settings → Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the public Pages URL.
